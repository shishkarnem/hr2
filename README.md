# Робот Рекрутер (RR) — AI Recruitment & Training Platform

Интеллектуальная платформа автоматизации найма, AI-скрининга резюме, тестирования, ролевых ситуаций и адаптационного обучения кандидатов с интеграцией в экосистему ProTalk.

---

## Возможности платформы

- **AI-скрининг резюме**: автоматический анализ кандидатов по критериям вакансии с выставлением объективных оценок и подробным фидбеком.
- **Интерактивные чек-листы и кейсы**: автоматическая генерация опросников и оценка ситуационных задач кандидатов.
- **Конструктор этапов обучения и тестов**: создание учебных регламентов, материалов аттестации и тестов с проверкой открытых ответов с помощью ИИ.
- **Индивидуальные лендинги компаний и вакансий**: публичные визитки с фирменным стилем, логотипом и адаптацией под корпоративные цвета.
- **Сквозная аналитика и биллинг**: учет баланса, транзакций (Robokassa), квот и прозрачный журнал списания токенов нейросети.
- **Чат-боты и интеграции**: Telegram-боты оповещений, авторизация, экспорт отчетов и интеграция с HH.ru.

---

## Стек технологий

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **Дизайн-система**: фирменный стиль **Apple Liquid Glass** (матовое стекло, размытие фона, акценты благородного золота, естественный регистр текста).
- **Backend**: Express.js, TypeScript, REST API, JSON-RPC.
- **База данных**: облачный **PostgreSQL («hr»)** на инфраструктуре **ProTalk Cloud** (доступ через HTTP Proxy API и протокол MCP JSON-RPC 2.0).
- **Хранилище файлов**: **ProTalk Storage** с CDN-доставкой и постоянными URL.
- **Нейросетевое ядро**: модели и боты ProTalk (основной рабочий бот `66337` и резервный ProMax `67370`).

## Запуск и развертывание

### Предварительные требования

- **Node.js**: версия 18.x или 20.x+
- **npm**: версия 9.x+

### Установка зависимостей

```bash
npm install
```

### Настройка окружения

Создайте файл `.env` (на основе `.env.example` при необходимости) и задайте конфигурационные переменные:

```env
PORT=3000
NODE_ENV=production
```

Все токены ботов, системные промпты и параметры подключения загружаются напрямую из защищенных конфигураций облачной базы данных ProTalk.

### Запуск в режиме разработки

```bash
npm run dev
```

Сервер запускается на `http://0.0.0.0:3000`.

### Сборка и запуск в продакшене

```bash
npm run build
npm start
```

Команда `npm run build` выполняет сборку клиентской части Vite в `dist/` и бандлинг серверного процесса в `dist/server.cjs`.

## Архитектурные стандарты

1. **База данных**: единственным источником истины является облачный PostgreSQL BD ProTalk («hr3»). Вся работа с данными ведется напрямую с базой данных PostgreSQL BD ProTalk.
2. **Файлы**: все изображения и документы хранятся в ProTalk Storage, а эндпоинты `/files/:id/:filename` работают по принципу прямого редиректа без создания дискового кэша.
3. **Верстка**:
   - Минимальный размер шрифта — строго **14px**.
   - Полный запрет капслока (UPPERCASE) в интерфейсе.
   - Запрет использования красного и зеленого цветов в контейнерах и блоках (только золото, янтарь и белый).
   - Мобильная адаптивность без горизонтального скролла табов.
4. **Рефакторинг**: не более 1000 строк на один файл кода, не более 5 файлов в одной папке.
